# diskin.me

Source of Michael Diskin's academic website, published at [diskin.me](https://diskin.me).

The site is built with Jekyll on the [al-folio](https://github.com/alshedivat/al-folio) v1.2 starter.
Shared layouts, styles, and scripts come from the pinned al-folio gems;
local files keep the site's content, configuration, and reviewed overrides.

- [AGENTS.md](AGENTS.md): working rules for this repository.
- [Migration record](.github/MIGRATION.md): runtime ownership, overrides, checks, and upstream updates.
- [Site audit](.github/SITE_AUDIT.md): remaining content and maintenance work.
- [al-folio v1.2 documentation](docs/README.md): upstream guides, kept unchanged.
